# ✿ Шпаргалка neovim

`<Пробел>` — главная клавиша (leader). Нажми его и подожди: появится меню всех команд.
Все команды работают и в русской раскладке. Закрыть эту шпаргалку: `q`.

## Самое нужное
| Клавиши | Что делает |
|---|---|
| `i` | начать печатать (режим вставки) |
| `Esc` | вернуться в обычный режим |
| `Ctrl+s` / `Пробел w` | сохранить |
| `Пробел q` | выйти |
| `u` / `Ctrl+r` | отменить / вернуть |
| мышь | работает везде: клики, выделение, прокрутка |

## Файлы и поиск
| Клавиши | Что делает |
|---|---|
| `Пробел e` | дерево файлов (`a` создать, `d` удалить, `r` переименовать, `l`/`h` открыть/свернуть) |
| `Пробел Пробел` | найти файл по имени |
| `Пробел fg` | найти текст во всём проекте |
| `Пробел fr` | недавние файлы |
| `Пробел fb` | открытые файлы |
| `Shift+h` / `Shift+l` | предыдущая / следующая вкладка |
| `Пробел bd` | закрыть вкладку |
| `/текст` | поиск в файле (`n` — следующее совпадение) |

## Код
| Клавиши | Что делает |
|---|---|
| `Tab` / `Enter` | выбрать / принять подсказку автодополнения |
| `gd` | перейти к определению |
| `gr` | где используется |
| `K` | документация под курсором |
| `F2` / `Пробел cr` | переименовать везде |
| `Пробел ca` | быстрые исправления |
| `Пробел cf` | отформатировать файл |
| `Пробел uf` | форматировать при каждом сохранении (вкл/выкл) |
| `Пробел xx` | список всех ошибок |
| `]d` / `[d` | следующая / предыдущая ошибка |
| `gcc` | закомментировать строку (`gc` — выделение) |
| `Alt+j` / `Alt+k` | переместить строку вниз / вверх |
| `Пробел r` | **запустить файл** (Python, JS, C, Bash, Lua…) |

## Терминал
| Клавиши | Что делает |
|---|---|
| `Ctrl+\` | открыть / спрятать терминал |
| `Пробел th` / `tv` | терминал снизу / справа |
| `Esc Esc` | выйти из терминала в обычный режим |

## Отладка (Python, C/C++)
| Клавиши | Что делает |
|---|---|
| `F9` | точка останова |
| `F5` | запустить / продолжить |
| `F10` / `F11` / `Shift+F11` | шаг через / внутрь / наружу |
| `Пробел de` | значение переменной |
| `Пробел dq` | остановить |

## Git
| Клавиши | Что делает |
|---|---|
| `]h` / `[h` | следующее / предыдущее изменение |
| `Пробел gp` | показать изменение |
| `Пробел gr` | откатить изменение |
| `Пробел gB` | кто написал строку |
| `Пробел gs` | статус репозитория |

## Окна
| Клавиши | Что делает |
|---|---|
| `Пробел \|` / `Пробел -` | разделить вертикально / горизонтально |
| `Ctrl+h/j/k/l` | перейти между окнами |
| `Пробел ss` | восстановить прошлую сессию проекта |

## Обслуживание
`:Lazy` — плагины (обновить: `U`) · `:Mason` — языковые серверы · `:checkhealth` — проверка
Настройки: `~/.config/nvim/` — тема в `colors/lavender.lua`, клавиши в `lua/config/keymaps.lua`.
